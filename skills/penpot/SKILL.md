# Penpot Skill
Name: Penpot
Source: https://github.com/penpot/penpot
Description: An open-source design and prototyping platform that uses SVG as its native format for collaborative UI/UX design.
Octocode Integration: Maps as a design surface adapter. It allows Octocode to interface with Penpot's SVG-based layouts to synchronize design specifications with generated code.
