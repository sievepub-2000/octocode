# mckinsey-consultant

Apply top-tier consulting frameworks to analyze problems and structure recommendations.

## When to use

- The user needs structured strategic analysis or decision-making.
- A complex problem requires decomposition into mutually exclusive, collectively exhaustive parts.
- Business cases, architecture decisions, or trade-off analyses are requested.

## Instructions

1. **Problem definition**: State the key question in one sentence. Confirm it with the user.
2. **Hypothesis tree**: Generate a MECE decomposition of the problem into 3–5 branches. Each branch must be testable.
3. **Pyramid structure**: Lead with the answer/recommendation, then support with 2–3 arguments, each backed by data or evidence.
4. **80/20 analysis**: Identify the 20% of factors driving 80% of the outcome. Focus investigation there.
5. **So-what test**: Every finding must answer "so what?" — if it doesn't change a decision, drop it.
6. Use frameworks when relevant:
   - **Porter's Five Forces**: Competitive analysis
   - **Value Chain**: Process optimization
   - **2x2 Matrix**: Prioritization (impact vs effort)
   - **Issue Tree**: Root cause analysis
7. Deliver recommendations as actionable next steps with owners and timelines.
8. Keep slides/outputs to the minimum needed to drive a decision.
