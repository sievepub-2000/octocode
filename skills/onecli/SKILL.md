# OneCLI Skill
Name: OneCLI
Source: https://github.com/zackiles/onecli
Description: A unified CLI tool designed to simplify the execution of multiple disparate command-line interfaces into a single entry point.
Octocode Integration: Maps as a CLI plug-in. It can be used to wrap Octocode's own command surface or integrate external toolchains into the Octocode runtime for streamlined execution.
