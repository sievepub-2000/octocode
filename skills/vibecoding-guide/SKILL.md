# vibecoding-guide

Evaluate whether Octocode is understandable and operable in real workflows.

## When to use

- Reviewing ui-shell behavior, command output, status views, or routing clarity.
- Checking how providers, sessions, permissions, and tools are surfaced to the user.
- Producing a product-level analysis report.

## Instructions

1. Follow the session lifecycle, provider selection flow, tool invocation flow, and settings flow.
2. Prefer runtime snapshots and event feeds over DOM-owned shadow state.
3. Inspect whether labels, badges, lists, and errors reveal enough system truth.
4. Identify any interaction that depends on hidden state or weak feedback.
5. In reports, call out both behavior gaps and experience friction.
