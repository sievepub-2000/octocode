# プライバシー方針 — Octocode

施行日: 2026-04-29
適用範囲: Apache License Version 2.0 のもとで配布される Octocode
v2026.4.29 以降。

## 1. Octocode について

Octocode はオープンソースのローカル CLI / WebUI / デスクトップ
コーディングエージェントです。ユーザー自身のマシン上で動作し、
ユーザーが設定した外部の大規模言語モデル（LLM）プロバイダー
（Anthropic、OpenAI、Gemini、OpenRouter、GLM、ローカルの OpenAI 互換
ゲートウェイなど）との対話を仲介します。

Octocode プロジェクトは、エンドユーザー向けのバックエンドサービスを
**運営していません**。Octocode 所有のクラウド、テレメトリ収集器、
中央集権的なアカウントシステムは存在しません。

## 2. ローカルで扱うデータ

Octocode はユーザーのマシン上で次のデータを処理します。ユーザーが
明示的に外部送信しない限り、これらはマシン外には出ません。

- WebUI / CLI / Canvas シェルに入力されたチャットメッセージ
- ツール実行の引数（ファイルパス、シェルコマンド、検索クエリ）
- セッションメタデータ: セッション ID、モデル ID、プロバイダー ID、
  タイムスタンプ
- プロバイダー設定: プロバイダー ID、ベース URL、既定モデル、権限
  モード、履歴制限
- 任意で Manage → GitHub に入力された GitHub 認証情報（PAT /
  fine-grained PAT / OAuth / GitHub App / Basic / Deploy Key）。
  ブラウザの `localStorage` のみに保存され、ランタイムバックエンドへは
  書き込まれません
- ツールが対象とした、ユーザー選択のワークスペース内のファイル

## 3. 第三者へ送信されるデータ

ユーザーがチャットメッセージを送信した時点で、Octocode はその
メッセージと、要求されたツールに応じた関連コンテキスト（ファイル、
コマンド出力、セッション履歴）を、ユーザーが選択したプロバイダー
エンドポイントへ転送します。この転送はユーザーのマシンから
プロバイダーへ直接、HTTPS で行われます。

これらプロバイダーのプライバシー慣行は当該プロバイダー自身の
プライバシー方針に従い、本書の対象外です。プロバイダーの選択は
ユーザーの責任となります。

カスタムの `ANTHROPIC_BASE_URL` 等を有効化した場合、リクエストは本家
プロバイダーではなくゲートウェイへ送られます。Octocode はこの
トラフィックを Octocode 管理のインフラ上で検査・記録・再ルーティング
することはありません。

## 4. Octocode が収集しないデータ

Octocode は次の行為を行いません:

- Octocode 所有のサーバーへのテレメトリ・クラッシュダンプ・利用
  解析の送信
- ユーザー選択のワークスペース外ファイルの読込・アップロード
- キーボード・画面・マイク・カメラ入力の収集
- ライセンス強制のためのフォンホーム
- ユーザー向けのリモートアカウント・プロファイル・アイデンティティの
  維持

Octocode が外向きに発行するネットワーク要求は次の 3 種のみです:

- ユーザーが設定した LLM プロバイダーエンドポイント
- Help → Check for Updates クリック時の GitHub Releases API
- `ui-shell/index.html` が参照する CDN アセット（`marked`、
  `highlight.js`、`KaTeX` の `cdnjs.cloudflare.com`、Google Fonts）。
  これらは自前ホスティングに置き換え可能です。

## 5. ローカルストレージ

ランタイムは、ユーザーのローカル設定ディレクトリ配下にセッションと
設定を保存します（Windows: `%APPDATA%\octocode`、macOS / Linux:
`~/.config/octocode` または `$XDG_CONFIG_HOME/octocode`）。これらは
ユーザーが完全に管理できる通常ファイルであり、いつでも削除可能です。

WebUI はブラウザの `localStorage`（`127.0.0.1` 上）に、選択言語、
配色テーマ、GitHub 認証情報を保存します。ブラウザのサイトデータを
クリアすると削除されます。

## 6. 児童プライバシー

Octocode は開発ツールであり、13 歳未満を対象とした製品ではありません。
児童からデータを意図的に収集することはありません。

## 7. 本方針の変更

新機能の追加に伴い本方針が改訂されることがあります。変更内容は
`CHANGELOG.md` に併記されます。実体的な内容変更があれば冒頭の
「施行日」が更新されます。
