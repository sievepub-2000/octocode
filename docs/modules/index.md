# Octocode Modules — Index

Octocode is a Rust workspace composed of focused crates plus a WebUI
shell. This index points to the consolidated module reference for
contributors and operators. The reference is provided in **English**
and **Japanese**.

| Document | Language |
| --- | --- |
| [octocode-modules.en.md](./octocode-modules.en.md) | English |
| [octocode-modules.ja.md](./octocode-modules.ja.md) | Japanese |

The runtime does not depend on these documents at compile time; they
are reference material only. The authoritative source of truth remains
the code under `crates/` and `ui-shell/`.
