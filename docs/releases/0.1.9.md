# OctoCode 0.1.9 / Desktop 1.132.3

New projects and chats receive separate working directories. The desktop now keeps terminal instances, draft attachments, audio capture, and artifact previews tied to their owning chat; late events from a deleted chat are ignored.

The project list focuses on project folders and their chats. Artifact indexes remain per-project internal records updated by the runtime; the manual refresh and raw JSON buttons have been removed.

The host validates a task's working directory, and the extension avoids reusing an idle terminal across tasks with the same directory. The release also includes provider refresh-token recovery, reviewed MCP lifecycle fixes, and the ongoing audit's runtime corrections. OAuth metadata discovery now rejects insecure non-loopback URLs, insecure advertised endpoints, and redirects.

Existing project chats retain their prior working directory until migrated explicitly. Project directories limit accidental cross-chat use of relative paths; they are not an operating-system sandbox for absolute paths or permissions-bypass mode.

Windows build, installation, and runtime acceptance evidence is recorded separately. Static review and source tests alone do not establish cross-platform, cold-start, or full audit acceptance.
