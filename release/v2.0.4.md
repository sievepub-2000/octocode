# OctoCode 2.0.4

桌面 **2.0.4**，核心扩展 **0.1.16**，Windows x64。

## 安全修复

- 三处 `@hono/node-server` 升级至 **2.1.3**，修复静态路径双重解码导致的访问控制绕过。
- 内置 Python 的 Tornado 升级至 **6.6**，修复微小分块资源消耗、折叠请求头和重定向问题，并固定轮子哈希。
- 对应 GitHub 本轮六项依赖告警；保留真实漏洞回归，不通过忽略告警处理。
