# OctoCode 2.1.1

桌面 2.1.1，核心扩展 0.1.22。提供 Windows x64 系统安装包和 Ed25519 签名发布清单。

- Agent 在右上角多模态窗口预览文件时，用独立标记显示其所在行列。聊天输入继续接收键盘输入，用户在文件编辑器里的选区也会保留。
- Webview 初始化期间关闭时，停止向已经关闭的窗口写入内容。恢复终端时，停止处理已经被清空或替换的编辑器输入。
- Windows Git 子进程管道断开时，错误由发起命令的调用方处理，避免未捕获的 `ENOTCONN` 影响扩展宿主。

已有 Windows 安装可原位升级，安装前请保存正在编辑的内容。安装包的版本、大小和 SHA-256 见 Release 附件 `octocode-release.json`，签名见 `octocode-release.json.sig`。
