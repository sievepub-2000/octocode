# OctoCode 2.0.1

桌面版本：2.0.1；核心扩展：0.1.14。目标平台：Windows x64。

## 修复

- 新建模型配置从空配置开始，不复制当前配置的模型、密钥或其他字段。
- 提供商选择显示真实保存状态，缺少提供商时要求补全配置，避免续接时出现 `provider unknown`。
- 保存未完成配置时保留已输入的模型和凭据，避免空提供商分支丢弃字段。
- 对话栏配置列表显示厂商名称，便于区分 OpenRouter 与 OpenAI Compatible 等来源。
- 打包扩展在开发宿主中运行时使用随包界面，不再误提示启动 HMR 开发服务器。
- 延长 daemon 首次健康探测的等待时间，避免冷启动期间过早超时；保留身份和凭据校验。
- 补齐新装时的 24 个随包 Skills；只补缺失文件，升级不覆盖已有内容，卸载保留技能数据。
- 统一 Skills 元数据解析中的 Windows 换行，修复有效技能在全新安装启动时触发 YAML 解析错误的问题；不修改用户技能文件。
- 首次配置页面在点击“完成”后才显示缺失密钥等校验错误，空白新装不提前报错，保存前校验保持有效。
- 延续 GitHub Skills 市场接入、已安装资源校验及用户数据保留机制。

## 升级说明

已有安装使用在线更新或受校验的原位安装包升级。正式目录为
`E:\Program Files\octocode`，升级保留 `data`、`workspace` 与 `environments`。
私有 GitHub 更新需要用户具有仓库访问权限；下载后必须通过签名、哈希和大小校验。
不要卸载后重装，也不要用开发目录覆盖正式用户数据。

## 验收状态

发布前必须完成正式安装中的 Nemotron 免费版 12 轮同会话测试，以及在线升级的
发现、下载、安装、重启和数据保留闭环。当前文档不代表这些步骤已通过；最终结果
以验收报告为准。在线升级依赖已发布的签名版本，经用户确认，先完成其余验收、推送源码和发布，再立即验证真实在线升级。
