# OctoCode v1.132.4

发布日期：2026-10-14（Asia/Shanghai）。桌面版本 **1.132.4**，核心扩展 **0.1.10**。发行平台：**Windows x64**。

## 更新内容

- 新项目和新对话使用独立目录，草稿、终端、附件、录音及产物预览绑定所属会话，删除会话后的延迟事件被忽略。
- Host 校验任务工作目录，避免跨会话执行；不同任务不会复用同一空闲终端。
- 项目列表聚焦目录与对话。产物索引保留为项目内部记录，移除手动刷新和原始 JSON 展示按钮。
- 修复窗口关闭期间的 MCP 延迟订阅和刷新，防止已释放视图继续刷新。
- 同步会话独立目录的回归测试，包含此前审查的模型提供商、OAuth 和 MCP 生命周期修复。
- 安装包排除 Cargo 构建缓存、不完整 stable Rust 工具链及账号认证内置扩展，修复构建和安装自检问题。
- 修正验收脚本的 bundled Rust 环境及退出码，使失败被记录、通过返回 0。

## 安装与验证

下载附件 `OctoCodeSetup-1.132.4.exe` 后运行。默认目录为 `D:\Program Files\OctoCode`。已有安装保存任务并关闭后进行原位升级；首次使用配置自己的模型服务与凭据。

安装包为 1,045,435,971 字节。SHA-256：

```text
53607C4B929B3F65D38331C2D1625372DB6B4D45894BA8D80BB205723E3511F6
```

最终安装包已在本机原生卸载旧程序、确认安装目录移除后重装。安装自检、冷启动、Host API 项目/会话/消息/设置/日志生命周期与隔离测试通过；GLM5.3 通过安装后的 headless 接口核验版本、进程路径、日志和哈希。源码测试 6,182 项通过、25 项跳过、0 项失败。

## 已知限制

- 未执行桌面 UI 操作、Linux/macOS 和真实 Docker Engine 安装验收；此 Release 仅提供 Windows x64 安装包。
- 两项 Windows 符号链接测试因账户权限不足跳过，其余 23 项为原有跳过项。
- 在线更新服务为占位配置，升级请下载新版安装器。
- 旧会话保持原工作目录；目录隔离不等同于操作系统安全沙箱。
- 本机可选 windows-mcp 的 Python 3.14 弃用警告使用本地补丁处理；补丁不在通用安装包中，第三方更新可能覆盖它。
