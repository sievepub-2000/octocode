# OctoCode 2.0.2

桌面 2.0.2，核心扩展 0.1.15。继承 2.0.1 的配置修复、全新安装和依赖安全修复。

- 交换 Light 与 High Contrast Light 的完整配色和语法高亮，主题名称及设置 ID 不变。
- Light 使用原白色方案；High Contrast Light 使用原 Solarized 暖色方案。后者按用户要求保留名称，不再代表原来的纯白高对比配色。
- 同步聊天界面、桌面主题、启动初始颜色及主题预览。
- 未设置主题时默认 Light；全新安装不再强制跟随系统深浅色。已有用户选择继续保留。
- 在授权的本机配置中增加实测达标的 OpenRouter 免费轻量路由，保留已有免费和付费配置；不将个人密钥或配置分发给其他用户。

验证结果见 [2.0.2 验收报告](../reports/v2.0.2-acceptance.md)。发布前验证和正式发布后的在线升级闭环分别记录，不把构建通过当作客户端升级完成。
