# OctoCode 2.0.8

桌面 2.0.8，核心扩展 0.1.20。按要求跳过 2.0.7 安装包发布，统一全新安装和在线升级的版本。

- 默认工作区初始化和标记丢失时补建安装目录下的 `workspace/Program`，同时迁移仍指向磁盘根目录的旧编辑器标签；保留脏缓冲区、非空用户文件和链接。
- 更新退出时停止空闲守护进程，防止安装期间抢先重开旧客户端；任务运行中或无法确认状态时延后更新，普通重启保留守护能力。
- 旧版启动静默升级时允许 Windows Restart Manager 正常关闭程序，不使用强制关闭参数。
- 不再在写入新文件前整目录删除旧入口、扩展和原生模块，避免更新中断后留下缺失 `main.js` 的客户端。
- 删除关于页的独立署名段落，缩短段落、条目和折叠文档间距。
- 保留 PS7 默认 agent 终端、正确账户网址和动态版本信息。

实际构建、发布和安装验收状态见[验证记录](../reports/v2.0.8-acceptance.md)。
