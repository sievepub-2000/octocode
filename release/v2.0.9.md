# OctoCode 2.0.9 源码版本

2026-11-12。桌面源码和 npm 锁文件版本已同步到 2.0.9。该源码快照包含核心扩展 0.1.20 和 Harness 1.0.17。

- 归档 82 份历史构建与验收日志、2.0.6 候选资产清单和隔离工作区启动复测记录。日志按原始字节保存，历史失败样例也随证据保留。
- 将 8 个核心扩展启动文件的换行符统一为仓库规定的 LF，源代码逻辑和依赖版本保持一致。
- 纳入此前已合入 `master` 的 Harness 1.0.17。Qwen 可以在无需工具时直接回答，文件读取等工具调用仍可用。[Harness 版本说明](harness-1.0.17.md)
- 本次复查工作区创建与保留、Windows 更新交接、安装器保留规则、签名测试和现有 2.0.8 发布资产校验。[验证报告](../reports/v2.0.9-source-verification.md)
