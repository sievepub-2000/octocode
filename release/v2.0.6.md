# OctoCode 2.0.6

桌面 2.0.6，核心扩展 0.1.18。

- 默认工作区初始化和缺失 `Program` 文件补建前移至桌面主进程，在扩展加载前执行。
- 显式配置安装目录的 `workspace` 也执行默认工作区初始化，重复启动保留已有文件内容。
- 系统版客户端更新改为静默原位升级，完成后从工作区重新打开客户端；保留数据、设置、登录和工作区。
- 兼容旧客户端无参数打开安装包的更新入口，检测已有安装后自动交接静默升级。首次安装保留安装向导；Windows 系统安装仍需权限确认。
- 公开 GitHub 仓库支持匿名更新检查和下载，继续验证 Ed25519 签名、文件大小和 SHA-256。

验证结果及尚未确认的项目见[验证记录](../reports/v2.0.6-acceptance.md)。
