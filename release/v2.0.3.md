# OctoCode 2.0.3

桌面 2.0.3，核心扩展 0.1.15。

- 修复系统级在线更新在应用退出期间丢失安装器启动操作的问题，改由独立 Windows shell 进程接手经过校验的缓存文件。
- 防止重复退出回调启动多个更新进程，保留系统权限确认和签名、大小、SHA256 校验。
- 继承 2.0.2 的浅色主题互换和默认 Light，以及 2.0.1 的配置与安全修复。

用户已明确确认手工测试正常，并授权发布 2.0.3。自动检查包括更新模块 28 项回归、退出交接回归、类型检查、生产构建及签名校验；不将用户手工确认改写为自动完成的主题、模型或长对话测试。范围见[发布记录](../reports/v2.0.3-release.md)，此前过程见[验收记录](../reports/v2.0.2-acceptance.md)。
