# OctoCode 2.0.5

桌面版 2.0.5，核心扩展 0.1.17。Windows x64。

- 默认工作区初始化时创建安装目录下的 `workspace\Program`，并迁移安装盘根目录遗留的同名空标记；非空文件及链接保留。正式安装的目标为 `E:\Program Files\octocode\workspace\Program`。
- 安装包内置 PowerShell 7，应用默认终端及代理命令执行均使用内置 `pwsh.exe`。右下角固定为代理命令终端，移除应用内旧版 PowerShell 默认入口。保留 Windows 自带的系统组件，不卸载操作系统的 PowerShell 5.1。
- 左下角“登录 OctoCode”直接打开 `https://octosys.cloud`，不添加路径、查询参数或尾部斜杠。
- 设置“关于”从实际桌面产品元数据读取版本及提交，升级后随客户端更新；独立扩展环境回退为扩展版本。
- 查询日志在右上角展示。右下角只展示终端命令及其输出；错误、复核状态、文件预览失败提示写入日志视图，其他编辑器离开终端区域。

安装包为 Release 附件 `OctoCodeSetup.exe`，同时提供 VSIX、`octocode-release.json` 和 Ed25519 签名。更新前保存任务并正常退出应用，保留原安装目录和用户数据。

验证结果及边界见[发布报告](../reports/v2.0.5-release.md)。本次不操作正式客户端；用户收到更新提示后进行升级和界面验收。未把相关自动测试当作正式客户端的实际升级验收。
