# OctoCode Harness 1.0.17

2026-11-06。此次版本更新仅涉及原生 Harness；桌面安装包仍为 2.0.8，核心扩展仍为 0.1.20。

- 修复 Qwen 3.8 在普通问候中重复回答、输出无关思考或强行调用工具的问题。原先按模型名强制 `tool_choice=required`，使不需要工具的回答无法正常结束；现在沿用自动工具选择。
- 保留工具定义及原生工具调用，读取文件等任务仍能正常执行。未更改模型名称、服务端模板、MTP 或内存保护。
- 为两个 Qwen 名称及普通模型增加实际请求构建回归测试，统一原生组件版本为 1.0.17，并同步 Cargo 锁文件。

正式安装路径的 OctoCode 已完成 Qwen 与 GLM 的真实多轮对话、算术和本地文件读取验收。GLM 连接错误另由本机失效代理设置引起，已在本机设置中修复；该机器的地址和凭据不进入通用代码。

构建、测试、实装及发布边界见[验证记录](../reports/harness-1.0.17-acceptance.md)。本次没有发布新的完整桌面安装包，现有 2.0.8 签名资产与自动更新源保持原版本。
