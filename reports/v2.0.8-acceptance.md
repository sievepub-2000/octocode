# OctoCode 2.0.8 验证记录

桌面 2.0.8，核心扩展 0.1.20。2.0.6 已发布资产保留；2.0.7 未发布安装包，按用户要求直接发布 2.0.8。

## 已确认原因

- 正式安装的 `workspace/Program` 存在，但恢复的编辑器仍指向 `E:\Program`，导致“找不到该文件”。此前补建文件没有迁移旧标签。
- 2.0.5 在线获取并校验 2.0.6 成功，但更新退出保留的 API 守护进程重开旧界面，安装日志显示正在运行而取消，正式版本仍为 2.0.5。
- 正式安装还缺少 `out`、内置扩展和部分原生模块，导致启动报 `ERR_MODULE_NOT_FOUND` 和界面加载失败。已使用同为 2.0.5、同提交的完整隔离副本及原始未插桩备份补回缺失程序文件，校验内置资源及模块摘要；没有覆盖用户数据。这是恢复旧版运行能力，不是升级完成。
- 已在真实 Inno 隔离安装器中复现：`InstallDelete` 先删除旧运行树，在替换写入前中断会留下缺失入口。取消这种预删除，交给正常文件替换和回滚。
