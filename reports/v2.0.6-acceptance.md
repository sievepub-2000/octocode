# OctoCode 2.0.6 验证记录

桌面 2.0.6，核心扩展 0.1.18，Windows x64。范围见[版本说明](../release/v2.0.6.md)。

## 修复及代码验证

- 工作区 `Program` 补建移至桌面主进程初始化，在窗口和扩展启动前执行；已存在文件保持内容。
- 显式配置安装目录下的默认 `workspace` 也执行初始化；Windows 路径比较忽略大小写。
- 系统版更新通过 Windows 提权入口传递静默原位安装参数，固定实际安装目录，完成后重新打开客户端。备份恢复更新同样改用静默参数。
- 旧客户端直接打开安装 EXE 时，安装器检测已有安装并交接静默升级；等待当前安装器正常退出后再执行，保留原用户上下文。首次安装仍显示向导，系统更新保留 Windows 权限确认。
- 公开仓库支持匿名检查和下载；认证请求仅发送至指定仓库 API，继续验证 Ed25519 签名、大小及 SHA-256，下载重定向不携带令牌。
- 核心完整回归：397 个文件通过、7 个条件跳过；6,253 项通过、28 项跳过。首次与打包同时执行时，打包清理 `dist` 导致四个解析器测试缺少 WASM；打包完成后完整重跑通过。
- 更新与恢复辅助进程 25 项、桌面 GitHub 更新 15 项通过。系统更新交接回归覆盖带空格路径、仅启动一次及错误日志。
- 真实 Inno 安装器回归通过：复用生产安装脚本，验证已有安装静默交接、新目录首次安装，以及路径中的空格、单引号和 `$`。测试使用独立目录和身份，没有写入正式安装注册表。
- 核心与桌面类型检查、改动文件 ESLint、提交钩子全包 lint 通过，没有增加抑制数量。

## 文件创建调查

原安装盘根目录空文件已完整移至本机诊断目录保留；没有删除非空文件或用户工作区内容。此前的管理员 FileIO 跟踪仅捕获工作区 `Program`，尚未捕获原根目录文件的创建者，原始跟踪数据仅留本机。

最终构建在实际 E 盘隔离客户端冷启动验证通过：首次创建、删除后补建、保留已有内容，均未出现根目录文件。关闭扩展仍能补建，证明该行为不再依赖扩展激活，见[启动记录](v2.0.6-isolated-startup.json)。完整环境初始化脚本回归也通过；首次隔离复制误排除依赖目录，修正复制范围后重跑通过。
