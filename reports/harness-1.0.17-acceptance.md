# Harness 1.0.17 验证记录

日期：2026-11-06（Asia/Shanghai）。此次仅更新原生 Harness，桌面 2.0.8 / 扩展 0.1.20 的完整安装包未重新发布。

## 原因和修改

真实 OctoCode 请求包含 23 个工具，并对 Qwen 普通用户输入强制 `tool_choice=required`。服务端因此不能直接结束文本回答，出现重复问候、无关思考和不必要的工具调用。

对同一请求固定随机种子，仅将该参数改为自动选择后，普通问候可正常结束。三个随机种子的问候均在 512 token 内结束，指定读取文件时仍返回原生 `read_file` 调用。服务端模板与上游一致，未改模板、模型名、MTP 或资源保护。

修改仅删除共享请求构建器中的模型名特例，保留完整工具定义；新增实际 actor 请求测试覆盖两个 Qwen 名称和普通模型。四个同步版本的原生 crate 及 Cargo.lock 均升级至 1.0.17。
