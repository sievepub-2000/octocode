## 最终运行时补充验收（10 月 27 日）

主题修正：High Contrast Dark 恢复完整历史 Dark 紫灰／品牌红色板，普通 Dark 黑底／棕铜配色不变；两个浅色主题不变。工作台、对话、预览及四套无缓存冷启动配色同步。修正前新增回归实际失败，修正后 52 项主题回归及 Webview 全套 156 文件／1636 项通过；三个主题在 1200、700、390px 下的 9 项真实 Edge 组件视觉检查通过，另有历史色板逐值比较和其他主题未变检查。GLM5.3 已通过本机 API 完成只读审查，处理记录见 `candidate-2.0-security/glm-theme-review-assessment-oct27.md`。此后正在重建安装包；下述旧安装包与 GUI 证据不能替代修正后安装包的验收。

## 安全、依赖及许可证

Electron 为 `43.8.3`，内嵌 Node 为 `24.22.0`。独立随附 Node 为 `26.12.1`，两者分别核验。对内嵌运行时既检查实际原生补丁，也测试应用启动边界，不能把配置下不触发解释为所有上游漏洞原生已修补。

已实施并复验 TLS/SPKI、非规范 IP、DNS NUL、Brotli、HTTP 连接投毒、Zod 集合上限和 Undici/EventSource 等防护。真实品牌 EXE、完整 ASAR 与未修改的打包 bootstrap 的 13 项攻击回归通过。新增 ConPTY 解包后，45 个解包文件及 18 个原生模块的大小、整文件哈希和分块哈希通过检查。

旧式 Node HTTP/HTTPS Agent 已使用连接不再复用，可能增加该路径的握手延迟；模型流式请求的 Undici 连接池保留复用。自定义 Node 启动快照、Node permission 模式不属于当前产品支持范围。

三套正式 Rust 锁、Markdown fuzz 锁及未随本次系统版调用的 Windows 用户更新器元数据锁均已审计为零漏洞、零警告。10 月 27 日重新拉取 RustSec 后发现的 zstd 系列问题已通过依赖升级修复，未忽略告警；更新后的原生 harness、CLI 已实际编译，压缩上下文隔离测试 2 项和 CLI 密码相关测试 16 项通过。实际 russh `0.64.1` 和相关密码、证书、Tokio 补丁已更新，保留已有本地修复及对应回归。桌面全部 59 套已跟踪 npm 锁文件（含开发工具、测试及两套独立运行时）及核心 pnpm 依赖均于当日重新审计为零漏洞。GitHub 当日实际返回 261 条未关闭告警，仍须推送默认分支后逐项确认服务器重新扫描的结果，当前不能声称 GitHub 告警清零。

第三方许可证覆盖生产 npm 包、运行时补充包、156 个 Python 分发和原生依赖。原始授权正文按实际来源保留；构建检查 VSIX 和安装载荷中的真实字节，避免旧 Electron 缓存混入。

## 4 号机 oMLX

已使用官方签名 `0.7.3.dev2`，采用绑定准确源码哈希的覆盖补丁，升级后重新部署并验证启动项覆盖持久化。主要修复是将索引器临时运算按 512 行处理并及时释放中间结果，保持模型、数学结果和上下文能力；没有提高 240 GB 上限，也没有缩小 1M 上下文、预填充步长或并发设置。

dev2 实际 237072 token 无缓存输入返回 HTTP 200，625.971 秒，预填充 384.08 token/s；第一轮仅产生 reasoning。保留完整历史的第二轮 237341 token 返回 HTTP 200 和可见文本，12.132 秒。独立内核对比索引结果相同，六次交替实测临时峰值由 2997164048 字节降至 883163154–899940370 字节，测量耗时没有增加。详细参数、签名、回滚和测量见 `maintenance/omlx/NATIVE-DEV.md`。

这些是有边界的实测，不能保证任意 1M-token、多请求同时运行和所有未来系统状态都不会耗尽物理内存。未执行物理 macOS 重启；已完成服务冷启动和配置持久性检查。10 月 27 日发现 macOS 27.2 更新，非交互 sudo 要求本机管理员密码，已请求用户在 4 号机本机授权，不索取或保存密码；本项仍待执行。
