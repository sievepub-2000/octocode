# 下一版本修复日志：工作区选择器与新任务对话框

日期：2026-10-08。状态：源码修复已完成本批回归；安装版仍为 desktop 1.132.2 / extension 0.1.8，新安装包尚未发布或升级。

本批修复四处已复现的问题：

- 删除当前工作区时取消尚未完成的远程选择，避免连接完成后重新选中并写回已删除项。清理连接监听、更新选择状态，同时保留清空会话草稿所需的 `onDidSelectWorkspace(undefined)` 通知。
- 浏览菜单行绑定构建该行时的具体 provider action。provider 注册顺序变化后仍执行原选项；原 action 被移除时不执行替代项。桌面、Web、移动端与自动化对话框统一使用同一绑定。
- 缺少可用工作区且新任务未指定存储位置时，保留 Workspace 的逐项禁用状态，使用 User 存储；已有任务的存储锁定和正常切换保持原行为。
- 可聚焦的禁用存储选项保留工作台焦点框，删除隐藏焦点的局部 CSS 覆盖。
