# OctoCode 2.0.5 发布与验证记录

桌面 2.0.5，核心扩展 0.1.17。Windows x64。范围见[版本说明](../release/v2.0.5.md)。

## 修复与边界

1. 默认工作区和安装初始化均创建 `workspace\Program`，重复初始化不覆盖已有内容；只移除安装盘根目录的同名空普通文件，非空文件、目录、链接均保留。发现的 `E:\Program` 为零字节；发布前没有改动它或正式安装。原始文件的创建进程尚未捕获，验收需观察新版本冷启动后是否再出现。
2. PS7 作为核心环境随安装包分发，设置默认 Windows 终端配置，并为原生代理指定 `GROK_SHELL=pwsh` 和内置 PowerShell 的 PATH。右下角创建的是原生 Shell，不是仅模拟输出的终端。Windows 系统 PowerShell 5.1 保留为操作系统组件；应用旧版默认终端入口禁用。
3. 账户导航固定为无后缀的 `https://octosys.cloud`；本轮不迁移云 API、令牌或认证后端。
4. “关于”读取桌面 `product.json` 的实际版本和提交；扩展宿主状态保留扩展自己的版本字段。
5. Output Channel 打开在右上角；右下角非终端编辑器移至右上角。代理错误、监督状态和文件预览错误退出终端输出链路，保留在日志中。

## 正式客户端验收交接

按用户要求，本轮不安装、不重启正在使用的 `E:\Program Files\octocode`，不改动其数据、工作区、登录或签名状态。用户收到更新提示后升级并测试：

- 冷启动后根目录不再出现空 `Program`，默认工作区标记存在且原文件内容保留。
- 右下角默认终端 `$PSVersionTable.PSVersion` 为 7，代理执行命令实际使用 PS7，重开会话后位置不变。
- 登录入口地址精确为目标根网址，“关于”显示 2.0.5 及本版提交。
- 日志、文件、预览在右上角显示；终端命令和输出保留右下角。

本轮未执行正式客户端的真实在线升级、冷启动界面或代理实任务验收；不将源码测试、打包核对算作这些项目通过。Linux、macOS 和 Docker 未执行本轮安装生命周期。
