GitHub Advisory Database 的十二条 Axios 漏洞区间覆盖旧解析版本，修补版本均为 1.20.0。对照记录中的全部区间，更新后的实际解析包不再命中。区间比较将 GitHub 的逗号合取规范化为 npm-semver 空格合取，并验证每条范围能解析。
