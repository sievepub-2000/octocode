# Code of Conduct

Octocode adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
in spirit. This file is a short, project-specific summary. The full
Contributor Covenant text is incorporated by reference and applies to
all interactions in this repository.

## Expected behavior

- Be technical, be specific, and be kind.
- Assume good intent. Ask clarifying questions before pushing back.
- Keep discussion grounded in the code, the runtime contracts, and
  reproducible behavior.
- Credit prior work and upstream projects where relevant.

## Unacceptable behavior

- Harassment, personal attacks, or sustained disruption of project
  spaces.
- Posting other people's private information without permission.
- Malicious activity: knowingly introducing vulnerabilities, supply
  chain attacks, or destructive automation.

## Scope

This code of conduct applies to all project spaces — issues,
discussions, pull requests, mailing lists, contact emails — and to
public spaces when an individual is representing the project.

## Enforcement

Reports may be sent privately to:

- `sievepub@outlook.com`
Maintainers will review reports and take action that, in their
judgment, restores a healthy collaboration environment. Possible
actions range from a warning, to a temporary ban, to a permanent ban
from project spaces. Maintainers will respect reporter privacy.
