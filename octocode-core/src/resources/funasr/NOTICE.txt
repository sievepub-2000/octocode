OctoCode speech input deployment

Runtime: ModelScope FunASR runtime-llamacpp-v0.2.6, official Windows x64 CPU release.
https://github.com/modelscope/FunASR/releases/tag/runtime-llamacpp-v0.2.6
License: MIT; see LICENSE-FunASR.txt. The HTTP wrapper is derived from this
release's runtime/llama.cpp/server/funasr_gguf_server.py. OctoCode modifications
add private loopback authentication, bounded uploads, cancellation, process
lifetime management and explicit UTF-8 decoding on Windows.

Models: FunAudioLLM/SenseVoiceSmall-GGUF and FunAudioLLM/fsmn-vad-GGUF.
https://huggingface.co/FunAudioLLM/SenseVoiceSmall-GGUF
https://huggingface.co/FunAudioLLM/fsmn-vad-GGUF
Both official model cards declare Apache-2.0; see LICENSE-Models.txt.
The models are third-party components, separately loaded by OctoCode Provider.

are in models/. Other inference engines can be selected through an external
OpenAI-compatible transcription endpoint. No PyTorch runtime is installed.
