# OctoCode changelog

## 0.1.0

- Introduced the Rust runtime host, SQLite/FTS/vector persistence, and unified provider routing.
- Integrated Grok as the only reasoning, planning, and execution harness.
- Retained VS Code as the editor, terminal, diagnostics, code-intelligence, and extension workbench.
- Added the local knowledge service, multimodal workspace, 17-language UI, and optional sign-in gate.
